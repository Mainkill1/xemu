# Native evidence recipe review

Independent review found no corruption in the collected attempts or published archives. It identified two future qualification gaps: individually eligible results could be compared despite different measurement identities, and early failures/partial publication could prevent evidence retention.

The summarizer now compares each collected job with its frozen prelaunch draft and requires identical analysis profile, storage contract, host/runner metadata, non-executable input identities and private runtime seed identities. Missing required reports block comparisons without changing canonical outcomes. CPU/frame samples remain unpooled.

The packager retains every available terminal artifact, records missing readable artifacts and unknown cleanup explicitly, verifies all archive members before publishing, and preserves interrupted destinations beside a repaired directory. Existing complete archives are checked against collected source inventories; changed evidence raises instead of overwriting history. Missing cleanup never proves the target stopped or qualifies measurements. The verifier reports unavailable analysis on early ineligible failures; it still rejects missing evidence on an eligible result and validates all available statistics and source hashes.

The retained fixture script exercises matching identity, changed profile, storage, workload, host, fixed input, early failure, null/rejected executable hashes, malformed optional job JSON, unreadable cleanup, and interrupted publication. Initial six fixtures produced five expected failures before the corrections; all twelve final fixtures pass. The two executable-identity cases and malformed JSON case each failed before their correction and pass afterward. These are local recipe fixtures, not additional machine runs or emulator correctness tests. No real run outcome or frozen campaign definition was edited.

Declared cache qualification proves private Mesa disk writes. It does not prove a warm driver RAM cache or fixed power/frequency. Product and emulator tests remain unchanged.
