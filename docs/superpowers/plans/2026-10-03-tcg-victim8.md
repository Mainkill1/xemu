# TCG victim8 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Qualify one real eight-entry victim cache for useful Deck performance.
**Architecture:** Owner-private FIFO history after the primary array, shared
invalidation generation/count, out-of-line miss helpers, original primary hit.
**Tech Stack:** QEMU C, GLib unit checks, Meson/Ninja, maintained HTTP runner.
**Spec:** `docs/superpowers/specs/2026-10-03-tcg-victim8-design.md`

## Global constraints

- Build option `xemu_tcg_victim_cache` defaults false; eight entries only.
- Preserve primary hash, array offsets, full lookup key and exclusive TB lifetime.
- Only dispatch owner touches victim payload; invalidators touch shared atomics.
- Steam Deck `.123`; maintained HTTP; explicit suite configuration for binary tests.
- No merge, questions, reference selfapproval, silent retry or cache waiver.
- Publish readable evidence in xemu; retain useful tests and tooling.

## Review focus

- Foreign targeted invalidation must discard a TB held only in victim history.
- Page-two remapping must reject a still-live physical TB remembered at another PC.
- A delayed global/generated fill must not retain pre-flush or reused pointers.
- Two overlapping invalidators must not appear idle after only one finishes.
- Default-off/on compilation must not turn code-shape changes into alleged gain.
